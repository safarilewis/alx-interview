# ALX Interview Prep

This repository contains solutions to common interview-style programming problems completed during ALX Software Engineering interview preparation.

## Problems solved

| Directory | Problem |
| --- | --- |
| `0x00-pascal_triangle` | Pascal's Triangle |
| `0x01-lockboxes` | Lockboxes |
| `0x02-minimum_operations` | Minimum Operations |
| `0x03-log_parsing` | Log Parsing |
| `0x04-utf8_validation` | UTF-8 Validation |
| `0x05-nqueens` | N-Queens |
| `0x06-starwars_api` | Star Wars API |
| `0x07-rotate_2d_matrix` | Rotate 2D Matrix |
| `0x08-making_change` | Making Change |
| `0x09-island_perimeter` | Island Perimeter |
| `0x0A-primegame` | Prime Game |

## Repository layout

- Each folder contains the solution for one problem.
- Implementations are written in Python or JavaScript, depending on the task.
- Some folders include a small runner script for local testing.

## Purpose

The goal of this repository is to document practical algorithmic problem-solving practice and provide clean reference solutions for future revision.
